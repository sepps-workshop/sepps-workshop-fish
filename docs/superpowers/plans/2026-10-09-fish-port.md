# Sepp’s Workshop fish port: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship one generated fish theme, `sepps-workshop`, installable with Fisher, after giving the design system an overlay value flattened over the terminal background.

**Architecture:** Two repositories. The foundation (`sepps-workshop-design-system`) gains `overlay.<name>.hex_terminal` and a gate for the text a shell draws on it. The port (`sepps-workshop-fish`) has a pure `buildTheme(tokens)` that walks `tokens.shell_roles` and writes one fish variable per line; `build.mjs` writes `themes/sepps-workshop.theme` and copies the README images.

**Tech stack:** Node.js 20+ (ESM, `node:test`), fish 3.4+ (tested with 4.9.3), Prettier. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-10-09-fish-port-design.md`

## Global constraints

- No hex value and no alpha arithmetic in the port's `src/` or `build.mjs`. A missing value is fixed in the foundation.
- The port ships no `conf.d/`, `functions/` or `completions/` directory: Fisher would install them.
- One theme, no variants. Theme file name `sepps-workshop.theme`.
- A fish variable with no role in the foundation is not written.
- `resolveTarget` throws on an unknown name; add no fallback.
- Docs are English, no emoji, paragraphs on one line (no hard wraps). The product is written "Sepp’s Workshop" with a typographic apostrophe, the company "sepp.med gmbh".
- Commits use Conventional Commits with a gitmoji and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Check `git status --short` before each commit.
- Nothing is pushed, tagged or published. The foundation release is the user's step.
- In the foundation, never hand-edit `tokens.json`, `dist/tokens.js`, `colors.css`, `preview/*.html` or the README tables between `<!-- tokens:… -->` markers; run `npm run build`.
- Deviation from the spec: the foundation's `CHANGELOG.md` is not edited here, because its `/release` skill writes the entry from the commits. Its contrast preview page gains the new rows because it is generated from the same report.

## Review focus

1. A user whose terminal background is not Darkblue: overlay backgrounds are opaque, so they are still readable, but the README must say the theme expects the Sepp’s Workshop terminal colours. Covered in Task 5.
2. A user switching from another theme: variables the theme does not set must not keep the old theme's values. Task 4's integration test sets a foreign value first and checks it is cleared.
3. A theme line fish rejects (`error: unsupported line`). Task 4's integration test fails on any stderr output.
4. A style name fish does not know. Task 3 maps styles to flags and Task 4 passes every value to `set_color`.
5. A future shell role that points at an overlay in no text class. Task 2's gate gives it no pairs silently; Task 2 adds a shape failure for it.

function shellPairs(tokens) {
  const pairs = [];
  for (const [key, name] of shellOverlays(tokens)) {
    const on = `overlay.${name} over surface.bg_terminal`;
    const bg = tokens.overlay[name].hex_terminal;
    for (const [label, fg] of overlayText(tokens, name) ?? [])

      if (k.startsWith(`${key}_`))
        pairs.push({
          label: `shell_roles.${k}`,
          fg: resolveTarget(tokens, role.color),
          on,
          bg,
        });
    }
  }
  return pairs;
}

- [ ] **Step 4: Implement the template.** Create `src/theme-template.mjs`:

```js
// Maps the foundation's shell roles to a fish `.theme` file.
// One pure function: tokens -> file content.
//
// fish's own colour surface is the fish_color_* and fish_pager_color_*
// variables: syntax highlighting and the completion pager. The sixteen
// ANSI colours belong to the terminal emulator, not to this port.
// File format: `man fish_config`, section THEME FILES.

import { resolveTarget } from "@sepps-workshop/design-system/tools/build-tokens";

// The file name without extension: what `fish_config theme choose` takes.
export const THEME_ID = "sepps-workshop";
const HOMEPAGE = "https://github.com/sepps-workshop/sepps-workshop-fish";

// Foundation style name -> fish colour flag.
const FLAG = { italic: "italics", underline: "underline", bold: "bold" };

// fish writes a colour as six digits, without the number sign.
const bare = (colour) => colour.slice(1);

// One role -> the value of its fish variables, e.g. "9eadc7 --italics".
// An overlay is a background. fish cannot blend, so it takes the value
// the foundation flattened over the terminal background.
function roleValue(tokens, role) {
  const parts = [];
  if (role.color) {
    const [group, name] = role.color.split(".");
    parts.push(
      group === "overlay"
        ? `--background=${bare(tokens.overlay[name].hex_terminal)}`
        : bare(resolveTarget(tokens, role.color)),
    );
  }
  for (const style of role.style ?? []) parts.push(`--${FLAG[style]}`);
  return parts.join(" ");
}

// [variable, value] for every fish variable a shell role lists.
export function themeVars(tokens) {
  return Object.values(tokens.shell_roles).flatMap((role) =>
    (role.fish ?? []).map((name) => [name, roleValue(tokens, role)]),
  );
}

export function buildTheme(tokens) {
  return (
    [
      `# name: '${tokens.meta.name}'`,
      `# url: '${HOMEPAGE}'`,
      `# preferred_background: ${bare(tokens.surface.bg_terminal)}`,
      "",
      ...themeVars(tokens).map(([name, value]) => `${name} ${value}`),
    ].join("\n") + "\n"
  );
}
```

import assert from "node:assert/strict";

mkdirSync(themes, { recursive: true });
copyFileSync(
  fileURLToPath(new URL(`../themes/${THEME_ID}.theme`, import.meta.url)),

// A previous theme that sets a variable Sepp’s Workshop leaves alone.

function fish(script, ...args) {
  const run = spawnSync("fish", ["-c", script, ...args], {
    encoding: "utf8",
    env: { ...process.env, XDG_CONFIG_HOME: config },
  });
  assert.equal(run.error, undefined, "fish must be installed to run this test");

fish_config theme choose previous
fish_config theme choose ${THEME_ID}
or exit 1
for name in (set --names | string match -r '^fish_(?:pager_)?color_.*')

end`;

  assert.equal(run.stderr, "");

  }

One dark colour theme for the [fish shell](https://fishshell.com/), built on sepp.med Darkblue with Sunset yellow as the accent. It colours what you type and the completion pager. There are no variants and nothing to configure: this is the one theme.

The colours come from the [Sepp’s Workshop design system](https://github.com/sepps-workshop/sepps-workshop-design-system), whose build refuses to ship a text colour that fails WCAG AA on its background. That includes the text on a selection and on the selected row of the pager.

## Install

With [Fisher](https://github.com/jorgebucaran/fisher):

```fish
fisher install sepps-workshop/sepps-workshop-fish
```

Fisher copies the theme into `~/.config/fish/themes/`. Nothing else is installed: no functions, no startup snippet.

Without Fisher, download the one file:

```fish
mkdir -p ~/.config/fish/themes
curl -fsSL https://raw.githubusercontent.com/sepps-workshop/sepps-workshop-fish/main/themes/sepps-workshop.theme -o ~/.config/fish/themes/sepps-workshop.theme
```

Then switch it on by adding one line to `~/.config/fish/config.fish`:

```fish
fish_config theme choose sepps-workshop
```

`fish_config theme choose` applies to the running session only, so this line is what makes the theme stick. To look before you commit, run `fish_config theme show sepps-workshop`.

You need fish 3.4 or later. The theme is tested with fish 4.9.

## Recommended companions

- **Terminal colours**: fish themes colour the command line, not the terminal. The theme expects a Darkblue terminal background (`#0d3174` in the design system) and looks best with the sixteen Sepp’s Workshop ANSI colours, which the terminal port provides. On another background the text stays readable, but selections and the selected pager row are tuned for Darkblue.
- **Font**: themes cannot ship fonts. The design system recommends [JetBrains Mono](https://www.jetbrains.com/lp/mono/), or [JetBrainsMono Nerd Font](https://www.nerdfonts.com/font-downloads) if your prompt shows icons.
- **Prompt**: this theme does not touch your prompt. The colours fish's own prompts use for the directory, user and host are set; a [Starship](https://starship.rs) prompt brings its own.

## How it is built

The theme file is generated. The design system says what colour a command, an option or an autosuggestion is, and lists the fish variables each of those roles feeds. This repository turns that list into a theme file. It contains no colour value of its own, and a test fails if one appears.

A few things follow from the palette and are deliberate:

- Commands are cyan-blue, not the accent: the cursor is already yellow, and a typed command is a call.
- Comments and autosuggestions share a colour. Comments are italic, which tells them apart.
- A selection darkens the background and keeps the syntax colours on top of it.
- Red is a signal only: errors, a failed status, the root user's directory.
- fish cannot blend colours, so the backgrounds of selections and of the selected pager row are computed for the Darkblue terminal background.

### Left at fish defaults

A variable the theme does not set keeps its fish default. These were left out on purpose, because the design system has no role for them:

- `fish_color_cancel`, `fish_color_history_current`, `fish_color_match`
- `fish_pager_color_background`
- `fish_pager_color_secondary_background`, `fish_pager_color_secondary_completion`, `fish_pager_color_secondary_description`, `fish_pager_color_secondary_prefix`

## Conventions

- **No colour in this repository.** No hex value and no alpha arithmetic in `src/` or `build.mjs`. A test fails on either.
- **The foundation decides which variables exist.** The template writes the fish variables that `shell_roles` lists and no others. A variable with no role stays at its fish default; list it in the README.
- **Overlays are backgrounds, flattened for the terminal.** A role whose colour is `overlay.<name>` becomes `--background=` with `overlay.<name>.hex_terminal`, and no foreground.
- **Foundation gaps go upstream.** A value the port needs and cannot find is fixed in `sepps-workshop-design-system`, not approximated here.
- **Resolve role names with `resolveTarget`.** It throws on an unknown name; do not add a fallback.
- **Fisher installs what it finds.** Only `themes/` may exist among `functions/`, `conf.d/`, `completions/` and `themes/`. Activation is the user's one line in `config.fish`.
- **Scope.** fish colours syntax and the pager. The ANSI palette belongs to the terminal port, the prompt to the Starship port.
- **Determinism.** Same tokens in, byte-identical theme out. `npm test` fails if `themes/` or `images/` is stale.
- **Writing.** The product name is written "Sepp’s Workshop" with a typographic apostrophe, the company "sepp.med gmbh". Docs are English, exact where technical, no emoji.
